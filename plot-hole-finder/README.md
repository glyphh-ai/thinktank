# plot-hole-finder

A demo project that analyzes a story (novel, screenplay, short fiction) and
surfaces potential plot holes, continuity errors, and logical inconsistencies.

## Idea

Feed in a manuscript and get back a structured list of issues such as:

- **Continuity errors** — a character's eye color changes, an object appears
  after being destroyed, timeline contradictions.
- **Logical gaps** — an event with no setup, an unresolved thread, a
  motivation that doesn't follow.
- **Character inconsistencies** — knowledge a character shouldn't have,
  out-of-character behavior.
